Postman API Testing Integration

Standard Postman v2.1.0 Collection & Environment for Postman Collection Runner

In addition to this interactive browser runner, the project includes an organized Postman collection matching all 7 testing categories with pre-request scripts and pm.test() assertions.

Collection postman/Digital_Wallet_API_Tests.postman_collection.json 39 requests organized into Groups A through G with JavaScript assertions
Environment postman/Digital_Wallet_Environment.postman_environment.json Configurable variables (baseUrl, sender_id, receiver_id)
How to run in Postman:
  1. Open Postman Desktop and click Import.
  2. Select both JSON files from the postman/ folder.
  3. Select Digital Wallet Environment in the top-right environment selector.
  4. Right-click the collection → Click Run collection → Click Run WalletPay Suite.
